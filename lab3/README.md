# Лабораторная работа №3 — вариант 1

## Цель работы

Изучить помехоустойчивое кодирование на базе программы лабораторной работы №2:
циклический код с обнаружением и исправлением одиночных ошибок, поле FCS и
эмуляция искажений в поле данных кадра.

Интерфейсы ввода (Input) и вывода (Output), топология и фиксированные параметры
COM-порта сохранены без изменений относительно лабораторной работы №2.

## Вариант 1

| Параметр | Значение |
|---|---|
| Макс. длина кадра (ЛР2) | 100 байт на весь кадр |
| Помехоустойчивый код | Циклический |
| Вероятность эмуляции ошибки | 10 % |
| Что искажается | один случайный бит одного случайного байта поля данных |
| Флаг | `450502-1` |

## Кадр

`Флаг | Type | Number | Data | Checksum(FCS) | Reserved`.

По заданию ЛР2 вариант 1 ограничение **100 байт — на весь кадр**, а не на
поле данных. Сейчас:

`8 (флаг) + 1 + 1 + 79 (данные) + 2 (Checksum/FCS) + 9 (резерв) = 100`.

Поле **Checksum** из ЛР2 используется как FCS (ЛР3): расширено до 2 байт за
счёт одного байта резерва. В шапке Status имя по-прежнему `Checksum`.

### Расчёт длины FCS

- Максимум поля данных: 79 байт = 632 бит.
- Для исправления одиночных ошибок: `2^r >= k + r + 1`.
- `r = 10`: `1024 >= 643` — подходит; `r = 9` — нет.
- Через COM-порт передаются байты ⇒ `FCS_BYTES = ceil(10/8) = 2`.
- Порождающий многочлен: `g(x) = x^10 + x^3 + 1` (деление столбиком над GF(2)).
- Код применяется только к полю данных; бит-стаффинг — после заполнения FCS.

## Эмуляция ошибок и статус

В блоке **Error emulation** — флажок **Enable**. При включении перед передачей
каждого кадра с вероятностью 10 % инвертируется один бит в поле данных
(FCS не пересчитывается).

Окно Status сохраняет шапку ЛР2 (`StartFlag FrameType FrameNumber Data Checksum`)
и показывает три представления последнего кадра:

1. до бит-стаффинга;
2. после бит-стаффинга (вставленные биты подчёркнуты);
3. после эмуляции ошибки (изменённые биты подчёркнуты; без ошибки строка
   совпадает с первой).

Приёмник по синдрому исправляет одиночную ошибку; в Output — восстановленный текст.

## Запуск

1. Установите зависимости: `pip install -r requirements.txt`.
2. Запустите `python serial_messenger/main.py`.
3. Выберите COM-порт и скорость (8 / N / 1 фиксированы).
4. При необходимости включите эмуляцию ошибок.
5. Наберите текст: символы копятся до заполнения поля данных, затем уходит кадр.

На обоих концах линии выбирайте одинаковую скорость (пара COM3 ↔ COM4).
