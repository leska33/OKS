# Лабораторная работа №4 - вариант 1

## Цель работы

Изучить методы доступа к моноканалу на базе программы лабораторной работы №3:
упрощённый CSMA/CD с эмуляцией занятости канала и коллизий.

Интерфейсы ввода (Input) и вывода (Output), топология, фиксированные параметры
COM-порта и структура кадра сохранены без изменений относительно ЛР3.

## Вариант 1

| Параметр | Значение |
|---|---|
| Вероятность занятости канала | 10 % |
| Вероятность коллизии | 40 % |
| Коллизия | в отношении отдельного байта |
| Дополнение к алгоритму | Jam-сигнал (`0xEE` x 4) |
| Основа | ЛР3 (циклический код, FCS, bit-stuffing) |

## CSMA/CD (упрощённо, без распараллеливания)

Три ключевых шага **в указанной последовательности** - и на передатчике, и на приёмнике:

1. **Прослушивание канала** - с вероятностью 10 % канал занят; ожидание слота и повтор.
2. **Обнаружение коллизии** - кадр уходит **побайтно**; с вероятностью 40 %
   коллизия вскрывается на **одном конкретном байте** (вариант 1).
   Байты до него уже ушли в линию; на этом байте - Jam.
   (Варианты 3-4 - коллизия кадра целиком; у нас так **не** сделано.)
   На приёме коллизия опознаётся по Jam.
3. **Случайная задержка** - стандартный binary exponential backoff:
   `k = min(n, 10)`, `r` из `[0, 2^k - 1]`, `delay = r * SLOT_TIME`.

На передатчике при коллизии: **Jam-сигнал** -> backoff -> повтор кадра целиком.
На приёмнике: сброс сборки по Jam -> backoff (при включённом Multiple access).

Параметры `SLOT_TIME_MS`, `MAX_ATTEMPTS` и значение Jam заданы в
`serial_messenger/backend/csma_cd.py`.

## Интерфейс

- **Error emulation** - как в ЛР3.
- **Multiple access** - разрешение/запрет эмуляции множественного доступа.
- **Collisions** - отдельно `*` через пробел по числу коллизий последнего кадра.
- **Status** - три строки кадра как в ЛР3.

Окна Input и Output не адаптируются к новым блокам управления.

## Запуск

1. `pip install -r requirements.txt`
2. `python serial_messenger/main.py`
3. COM-порт и скорость (8 / N / 1 фиксированы); пара COM3 <-> COM4.
4. При необходимости - Error emulation и/или Multiple access.
